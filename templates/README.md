# __NAME__

Standalone Bash glue using the strictbash profile. Requires Bash 4.4+,
ShellCheck 0.10.0 and strictbash.

```bash
bash main.sh
make check
make test
```

Install strictbash with `cargo install --git https://github.com/ilvar/strictbash --locked`.
Read `strictbash --help` for the full policy and diagnostic contract.
